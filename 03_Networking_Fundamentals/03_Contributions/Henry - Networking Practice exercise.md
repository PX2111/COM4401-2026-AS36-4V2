In this worked example of a network, the library server is hosting a webpage and the Staff PC is acting as the client pulling the web-page from the library servers IP address by specifying the different host address.
Its tested by pinging the server from the staff PC with the ping command to test the connection, which comes back with 0% lost packets meaning its working fine, then the web-page created and hosted on the library server
is tested by installing a browser on the staff pc and using the servers IP address (specifying host) into the address bar to see if the web-page displays, which it does.
