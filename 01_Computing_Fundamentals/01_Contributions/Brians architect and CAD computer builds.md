## Overview

This workstation has been designed for architects and CAD professionals who require strong processing power, excellent graphics performance, sufficient memory capacity, and a high-quality display. The build focuses on maximizing productivity while remaining within budget.

---

# Parts List

## Case

**Component:** Case

**Title:** Montech X5M Micro ATX Mini Tower White with Tempered Glass Side Panel

**Price:** £24.98

**Justification:**

I chose the Montech X5M because it is an affordable case that is fully compatible with the Micro ATX form factor used by this build. It provides enough space for the motherboard, graphics card, and CPU cooler while maintaining a compact footprint suitable for an office environment.

The case also includes excellent airflow and comes with pre-installed fans, reducing setup complexity and helping ensure sufficient cooling for all components. Built-in cable routing and cable management features make assembly easier and result in a cleaner final system.

---

## CPU

**Component:** CPU

**Title:** AMD Ryzen 7 9700X

**Price:** £244.99

**Justification:**

I selected the Ryzen 7 9700X because it offers 8 cores and 16 threads, making it highly capable of handling multitasking and productivity workloads.

Architectural and CAD software can place significant demands on the processor, particularly when rendering models, handling complex projects, or running multiple applications simultaneously. The Ryzen 7 9700X provides the performance required to ensure smooth operation without slowdowns or lag.

---

## Motherboard

**Component:** Motherboard

**Title:** MSI PRO B840M-B AM5 DDR5 Micro ATX

**Price:** £89.94

**Justification:**

The MSI PRO B840M-B was selected because it offers excellent value while supporting AMD's AM5 platform, ensuring full compatibility with the Ryzen 7 9700X.

Its Micro ATX form factor helps keep the system compact and suitable for office workspaces. The board provides two DDR5 memory slots, which is sufficient for the selected 32GB memory configuration.

Additionally, it includes a PCIe x16 slot that can fully support the bandwidth requirements of the Radeon RX 9070 XT, ensuring maximum graphics performance for CAD and design workloads.

---

## Graphics Card

**Component:** GPU

**Title:** Gigabyte Radeon RX 9070 XT GAMING OC ICE 16G

**Price:** £649.99

**Justification:**

The Radeon RX 9070 XT is the primary performance component of this workstation. With 16GB of dedicated VRAM, high clock speeds, AI accelerators, matrix cores, and AMD's latest RDNA 4 architecture, it provides excellent performance for modern professional workloads.

Architectural design software, 3D modelling applications, rendering, and AI-assisted workflows can place significant demands on graphics hardware. Allocating a larger portion of the budget to the GPU ensures the system remains capable of handling complex projects and future software developments.

---

## Memory

**Component:** RAM

**Title:** TEAMGROUP T-Force Vulcan DDR5-5600 CL40 32GB (2×16GB)

**Price:** £379.99

**Justification:**

This build uses 32GB of DDR5 memory running at 5600MHz, providing sufficient capacity and speed for modern CAD and architectural software.

Large projects often require substantial memory resources, and having 32GB available helps prevent reliance on virtual memory stored on disk, which can significantly reduce performance. The dual-channel configuration also ensures optimal memory bandwidth.

---

## CPU Cooler

**Component:** CPU Cooler

**Title:** be quiet! Pure Rock Slim 2 Air Cooler

**Price:** £14.99

**Justification:**

The Pure Rock Slim 2 provides a cooling capacity of up to 130W TDP, making it more than capable of cooling the Ryzen 7 9700X under normal operating conditions.

An air cooler was chosen instead of an all-in-one liquid cooling solution because it offers greater long-term reliability, requires less maintenance, and presents fewer potential points of failure.

---

## Storage

**Component:** Storage

**Title:** TEAMGROUP MP33 1TB M.2 NVMe SSD

**Price:** £29.72

**Justification:**

The TEAMGROUP MP33 provides 1TB of NVMe storage and delivers read/write speeds of approximately 3300MB/s.

This performance is more than sufficient for operating system responsiveness, application loading, and handling CAD project files. The drive also offers excellent value for money while providing enough storage capacity for professional workloads.

---

## Power Supply

**Component:** PSU

**Title:** be quiet! Straight Power 12 750W Fully Modular 80+ Platinum

**Price:** £19.99

**Justification:**

The Straight Power 12 provides 750W of power, which is sufficient to support both the Ryzen 7 9700X and Radeon RX 9070 XT under heavy workloads.

Its 80+ Platinum efficiency rating improves power efficiency and reduces wasted energy. The fully modular design simplifies cable management, and the 10-year warranty increases confidence in the unit's long-term reliability.

---

## Monitor

**Component:** Monitor

**Title:** MSI MAG 272QPW QD-OLED X28 26.5" WQHD 280Hz

**Price:** £378.95

**Justification:**

The MSI MAG 272QPW uses QD-OLED technology, providing exceptional colour accuracy and image quality. This is particularly beneficial for architecture and design-focused work where accurate visual representation is important.

The monitor features:

- 2560×1440 (1440p) resolution
- HDR support
- Deep blacks and strong colour reproduction
- 280Hz refresh rate
- Built-in speakers

The higher resolution allows architects to view detailed designs and models with greater clarity.

To further improve productivity, the existing monitors currently used by staff will be cleaned and reused as secondary displays, creating a dual-monitor setup. This is highly beneficial for CAD and architectural workflows where multiple applications, drawings, and reference materials often need to be visible simultaneously.

---

# Peripherals

CAD software does not require any specialised keyboards, mice or other hardware.

To reduce how much money is being spent, the existing keyboards, mice, and headsets will be cleaned and reused. This approach saves money while still providing employees with the necessary peripherals that they need for their work.
