# Software Engineering

This is the Recommendation and Flowgorithm build for the 'Pennine Pizza' Pizzeria order handling system. The Software life cycle methodology we followed was the waterfall method as it provided the structure and careful decisions needed for such a system. each Section of the Document includeing all the work for said section was created by a different team member and all coagulated in the same word document.
